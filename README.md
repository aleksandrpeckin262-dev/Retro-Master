# Retro-Master - простая (для пользователя) утилита на пайтон, превращающая интерфейс windows 10 в прошлые версии windows: 95, 98, XP, vista, 7.
Для коректной работы программы необходимы права администарота (программа будет работать и без них, но она не сможет заменить шрифт, звуки и еще некоторые вещи).
Проект распространяется под лицензией Apache License 2.0.
В этой версии был полностью убран баг со смертью GUI рабочего стола и добавлены новые иконки.

Баги: при нажатии на start открывается проводник.

Что будет добавленно в следуйщем обновлении: повышено качество обоев, добавленно еще больше иконок.

⚠️ВНИМАНИЕ - проект не забилжен, он представляет из себя код на пайтон и файлы!
⚠️ВНИМАНИЕ - в проекте по умолчанию стоят пути файлов через том D, если вы скачаете его на другой диск программа перестанет работать (вы можете изменить пути в коде и тогда это не проблема).
