# Retro-Master - простая (для пользователя) утилита на пайтон, превращающая интерфейс windows 10 в прошлые версии windows: 95, 98, XP, vista, 7.
Для коректной работы программы необходимы права администарота (программа будет работать и без них, но она не сможет заменить шрифт, звуки и еще некоторые вещи).
Проект распространяется под лицензией Apache License 2.0.
