# Retro-Master - простая (для пользователя) утилита на пайтон, превращающая интерфейс windows 10 в прошлые версии windows: 95, 98, XP, vista, 7.
Для корректной работы программы необходимы права администратора (программа будет работать и без них, но она не сможет заменить шрифт, звуки и еще некоторые вещи).
Проект распространяется под лицензией Apache License 2.0.

Баги: при нажатии на start открывается проводник.

Что будет добавлено в следующем обновлении: смена шрифта для win XP.

⚠️ВНИМАНИЕ - В этой версии проекта пути стоят через диск C, для людей без диска D.
