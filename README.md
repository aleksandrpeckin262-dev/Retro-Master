# Retro-Master - простая (для пользователя) утилита на пайтон, превращающая интерфейс windows 10 в прошлые версии windows: 95, 98, XP, vista, 7.
Для коректной работы программы необходимы права администарота (программа будет работать и без них, но она не сможет заменить шрифт, звуки и еще некоторые вещи).
Проект распространяется под лицензией Apache License 2.0.
В этой версии были пофикшены баги со смертью GUI рабочего стола, все версии теперь работают со 100% стабильностью. Были зашакалены некоторые спрайты для корректной работы программы.
Баги: 1 -  в папке проекта создаются файлы со спрайтами обоев и курсорами, 2 - фикс хот бара в версии вин95 и вин98.
Надо доделать: 1 - смену иконок ПК и корзины (стоят заглушки), 2 - отполировать все остальные версии (добавить смену шрифта и хот бара).
