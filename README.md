# Retro-Master - простая (для пользователя) утилита на пайтон, превращающая интерфейс windows 10 в прошлые версии windows: 95, 98, XP, vista, 7.
Для коректной работы программы необходимы права администарота (программа будет работать и без них, но она не сможет заменить шрифт, звуки и еще некоторые вещи).
Проект распространяется под лицензией Apache License 2.0.
В этой версии была изменнена архитектура проекта, добавлена работоспособная версия windows XP (готова примерно на 75%, осталось добавить хот-бар и счмену шрифтов), а так же были добавлены другие версии, но они завершены максимум на 10%.
Баги: 1 - виндовс виста ничего не делает, 2 - иногда кнопка reset полностью стирает весь GUE виндовс (фиксится перезагрузкой или повторным нажатием reset на версии win95).
